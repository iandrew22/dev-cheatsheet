Terminal Basics

Navigation
pwdShow your current folder location
lsList files in current folder
ls -laList all files with details (including hidden)
cd folder-nameGo into a folder
cd ..Go up one folder
cd ~Go to your home directory
Files & Folders
mkdir my-projectCreate a new folder
touch file.txtCreate a new empty file
cp file.txt copy.txtCopy a file
mv file.txt new-name.txtRename or move a file
rm file.txtDelete a file
open .Open current folder in Finder
🌿

Git

Start or Connect a Repo
git initStart a new git repo in current folder
git clone <url>Download a repo from GitHub
Everyday Workflow
git statusSee what files have changed
git add .Stage all changed files
git add file.txtStage a specific file
git commit -m "message"Save a snapshot with a description
git pushUpload commits to GitHub
git pullDownload latest changes from GitHub
Branches
git checkout -b my-branchCreate and switch to a new branch
git checkout mainSwitch back to main
git merge my-branchMerge a branch into current branch
🐙

GitHub CLI (gh)

gh repo createCreate a new GitHub repo
gh repo clone owner/repoClone a repo from GitHub
gh pr createOpen a pull request
gh pr listList open pull requests
gh issue listList open issues
gh auth statusCheck your GitHub login status
🤖

Claude Code

Starting Claude Code
claudeStart Claude Code in current folder
claude "fix the bug in app.js"Start with a specific instruction
Commands Inside Claude Code
CommandWhat it does
/helpShow all available commands
/clearClear the conversation and start fresh
/reviewReview current branch changes
Ctrl + CCancel current action
Ctrl + DExit Claude Code
Things You Can Ask Claude Code
  • "Create a new React component for a login form"
  • "Explain what this function does"
  • "Fix the error in this file"
  • "Commit my changes with a good message"
  • "Create a pull request for this branch"
  • "What files changed in this project recently?"
🔄

Typical Daily Workflow

1
cd my-project Navigate to your project folder
2
git pull Get the latest changes from GitHub
3
git checkout -b my-feature Create a new branch for your work
4
claude Open Claude Code to help you build
5
git add . Stage your changes
6
git commit -m "add feature" Save a snapshot with a description
7
git push Upload your branch to GitHub
8
gh pr create Open a pull request for review
