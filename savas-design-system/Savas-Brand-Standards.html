06

Usage rules

DoUse ink text on mint, coral, marigold and lavender fills. Never white.
DoUse mint-text / coral-text when an accent colors body-size text.
DoKeep one serif-italic flourish per heading, in coral.
Don'tSet small text in mint, mint-ink or mute on white. They fail AA below large size.
Don'tIntroduce new hexes. Add a token to tokens.json first.
Don'tStack more than two accents in one component.

07

Figma ⇄ code workflow

Tokens and components sync both ways. Page layouts go design → code only.

1Edit in FigmaDesigners change Variables and components in the Savas Design System file.
2Export tokensVariables export to tokens.json (Tokens Studio or the Variables API) and land in a PR.
3Buildpython3 build.py regenerates tokens.css and this page. The site consumes tokens.css.
